# Аниметрек

Личный трекер аниме поверх [Shikimori](https://shikimori.io): где остановился, новые серии, сезоны по порядку («1 сезон», «2 сезон (название)», «3 сезон, часть 2»).

- Прогресс хранится в аккаунте Shikimori — общий на всех устройствах.
- Смотреть — на своих сайтах (AnimeLib, YummyAnime): кнопка открывает сохранённую страницу сезона или поиск.
- Без сервера: статическая страница на GitHub Pages, ставится на телефон как приложение.

Client ID и Client Secret приложения Shikimori вводятся на устройстве и в репозиторий не попадают.
